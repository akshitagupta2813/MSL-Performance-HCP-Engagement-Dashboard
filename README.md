# MSL Performance & HCP Engagement Dashboard

## Overview
Interactive Power BI dashboard analysing MSL field force performance and HCP engagement across 10 countries, 5 therapeutic areas and 3 years of data 
(2022–2025).

## Business Questions Answered
- Which region has highest MSL interaction volume?
- What % of interactions are with Priority HCPs?
- Which product is discussed most across TAs?
- Which MSLs are top performers?
- How do interaction outcomes vary across markets?

## Key Insights
- Face to Face interactions account for 37% of all engagements
- Priority HCPs account for 60% of all interactions
- ProductAlpha is most discussed at 32% of all interactions
- Oncology has highest interaction volume across all therapeutic areas

## Tools Used
Power BI | DAX | Data Modelling | Data Cleaning | Calculated Columns

## Dataset
Dummy dataset created for portfolio purposes using realistic MSL and HCP metrics.
Note: All data is completely fictional and does not represent any real company or individual.
